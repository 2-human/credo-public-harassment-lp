Colour tokens

Today the Webflow project has 1,258 styles with 44 hard-coded colours, including six different reds. In the new system every colour is a Webflow variable with the prototype's name; the right-hand chips show the colours each token replaces.

Type

Two fonts, already loaded on every page: Hanken Grotesk for text and Inconsolata for labels and numbers. What changes is the scale: body text moves off Webflow's default Arial #333, and headlines get proper phone sizes.

Shared components

Built once in Webflow and reused, so a change lands on every page at the same time.

  • Header (navbar): already shared on 61 page slots. Gains the tracked phone number and a "Free review" button on phones (PBI-06). exists
  • Footer (Footer-MJ): on the 31 new pages today; replaces the unlinked copies of the old dark footer on the 21 old pages. extend
  • Hero form: Hero-Form and Hero-Form-For-New-Pages merged into one component with a variant property; replaces the old purple multi-step form. merge
  • CTA button: one button with a text property, so the labels stay consistent (wording waits on decision D3). new
