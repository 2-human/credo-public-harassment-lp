# Review packet: PBI-11 (Title Case on paragraph copy) + D16 (state pages kept out of search)

## Context (fixed)
- A law firm's lead-generation landing pages in Webflow. **staging.credolegal.com is the production site being built**
  (Webflow site `6ab90fb0761d44332faf21c8`); all changes are made and verified there.
- The previous review (DS-7) flagged body paragraphs shown in Title Case ("At Credo Legal, Multiple Collectors Mean…").
  Cause: the what-we-do paragraph class `text-block-16` had `text-transform: capitalize`, on every landing page (it predates
  DS-7). The operator approved fixing it.
- The operator decided (D16) that the 13 state pages (/ohio, /kentucky, /utah, /south-dakota, /missouri, /kansas,
  /california, /minnesota, /maryland, /colorado, /new-york, /new-jersey, /florida) **should not rank for now**. Until today
  they carried their old heads: `robots index, follow` and canonical + og:url pointing at the home page
  (`https://start.credolegal.com/`). The 38 other landing pages already use `noindex, nofollow` with canonical + og:url
  pointing at the page itself (`https://start.credolegal.com/{slug}`); start.credolegal.com is the domain the site will
  go live on.

## Change 1: Title Case
- One style change: class `text-block-16`, `text-transform: capitalize` → `none` at the base breakpoint (no other breakpoint
  sets it). Copy was already written in sentence case, so no copy edits were needed.

## Change 2: D16
Per state page, the page head code was rewritten as **the page's own head, unchanged except 3 lines**:
```
<meta name="robots" content="noindex, nofollow">
<link rel="canonical" href="https://start.credolegal.com/{slug}">
<meta property="og:url" content="https://start.credolegal.com/{slug}">
```
(was `index, follow`, and `https://start.credolegal.com/` for both URLs). Everything else in the head (Twitter card,
JSON-LD LegalService whose `url` stays the firm's home page, Finsweet, Inputflow, Mouseflow, GTM, the #gtmform guard, South
Dakota's own `.addressmj` style block and the heading style block) is untouched. Both changes were published together.

## Evidence (live site, 29 Sep; trackers blocked; no lead sent)
- `verify-ds7-states.py` (served HTML, 13 pages): exactly one robots meta and it is `noindex, nofollow`; exactly one
  canonical and one og:url, both `https://start.credolegal.com/{slug}`; **the served head contains the backed-up old head
  verbatim with only those 3 lines replaced**; plus the earlier checks (new form only, state copy, SEO title, phone embed,
  per-state numbers, `-old` 404). **13/13 OK.**
- The site has no sitemap.xml (404) and an empty robots.txt, so no sitemap lists the state pages.
- Served stylesheet: `.text-block-16 { … text-transform: none; … }`; the tablet/phone rule for the class only sets padding and
  font size.
- `verify-titlecase.mjs` (rendered, 54 published pages): every visible element with 6+ words of its own text is checked for
  computed `text-transform: capitalize`: **0 on 54 pages** (51 what-we-do paragraphs seen; the class is used exactly once per page, always on that
  paragraph, so no short label shares it). Negative control: re-adding the
  old rule in the browser makes the same check report it.
