4 · How to build it in Webflow

Recommended — rebuild natively using your existing site classes, so it stays editable and matches the rest of the footer/site. Use the structure below and the style values above. The Embed route (§5) is a faster fallback but is not editable in the Designer.

Suggested Webflow structure (Footer element → containers → link blocks):

Footer (bg #111418, 2px top border #ff6b73, pad 40/0/26) └ Container (max-width 1180, gutter 24) ├ Div .footer-top (flex, space-between, 1px bottom divider #2a2f37) │ ├ Link block → logo image (h28, white/inverted) │ └ Nav .footer-links (flex, gap 22) → 6 Text Links (new tab) ├ Div .footer-grid (flex, gap 20/64) │ ├ Div → Entity (700) + Address (13px, muted) │ └ Div .footer-contact (3 rows: mono Label + Link) ├ Paragraph .footer-legal (12px, muted, max-width 760) ├ Paragraph .footer-states (10px mono, uppercase, muted) └ Div .footer-bottom (flex, space-between, 1px top divider) ├ Text © 2026 Credo Legal. All rights reserved. └ Text Attorney Advertising (mono, uppercase)
  • Logo: use the brand asset (white/inverted on the dark bg). Source PNG: assets/credo-logo.png (480×158) — or the master SVG if the brand kit has one.
  • External links: set each to open in a new tab in Webflow's link settings.
  • Responsive: below ~640px the top row and the two columns stack to a single column (breakpoint already in the CSS).
  • Global footer: build it as a Webflow Symbol/Component so every LP shares one instance — mirrors how it works in the prototype (one render, all pages).

6 · Two decisions to confirm before it ships

Phone numbers. This footer shows the firm's company lines ((212) existing · (718) new). The campaign hero/nav CTA uses a separate call-tracking (DNI) number. Confirm the footer should show the company lines, not a tracking number.
Copyright year. Set to 2026 here; the live site still reads 2025. Confirm which to keep.
NAP consistency. Entity/address reproduced verbatim from the live LP ("…P.A.", NY). It differs from other Credo profiles — worth a compliance check before public launch.
